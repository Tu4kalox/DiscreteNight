# Система анализа канала связи (special for Колесников С. Г.)

## Базовая информация

Приложение создано для расчета отношения сигнал/шум для пары антенна-спутник с заданными координатами, а также для подбора антенн с минимальным отношением сигнал/шум для заданных спутника и координат. Приложение является легко масштабируемым, запрос на добавление новых функций отправлять в **Telegram:**

> https://t.me/Tu4ka993
> https://t.me/AsiH2O

## Функции меню

### 1. Расчет отношения с/ш

В каждом из блоков можно выбрать антенну/спутник в выпадающем списке. В случае, если требуется задать параметры на месте, в выпадающем списке выберите *"Добавить"* и нажмите на кнопку *"Задать параметры антенны/спутника"* — откроется окно создания временного объекта. Введите нужные параметры, нажмите *"Сохранить"* и вернитесь обратно. После выбора антенны и спутника, введите их *координаты* (географические для антенны и ECEF для спутника в метрах), а также *скидки на замирания, другие потери, потери на границе, потери реализации, скорость передачи, температуру* \[дБ, дБ, дБ, дБ, бит/с, К] — в соответствующее окно. После, нажмите на одну из кнопок расчета в зависимости от источника сигнала. При получении ошибки, проверьте корректность ввода данных 
(см. Ошибки).

### 2. Подбор антенны

Система ввода данных реализована точно так же, как и на экране расчета, за исключением того, что антенны выбирать не требуются — система считает *отношение с/ш* для всех антенн из файла *antennas.txt* (см. Файлы antennas.txt и satellites.txt). Результаты выводятся в окно в порядке возрастания *отношения с/ш*, для каждой антенны отображаются ее имя и параметры

### 3. Добавление и изменение антенны/спутника

#### Добавление

Для добавления антенны/спутника перейдите в соответствующее окно добавления и изменения и в выпадающем списке выберите *"Добавить"*. Введите имя и параметры антенны/спутника и нажмите *"Сохранить"*. В случае успешного добавления, в верхней части окна появится уведомление. При получении ошибки, проверьте корректность ввода данных (см. Ошибки).

#### Изменение

Для изменения антенны/спутника перейдите в соответствующее окно добавления и изменения и в выпадающем списке выберите антенну/спутник, которую хотите изменить. Все поля автоматически заполнятся актуальными значениями. Измените данные и нажмите *"Сохранить"*. В случае успешного изменения, в верхней части окна появится уведомление При получении ошибки, проверьте корректность ввода данных (см. Ошибки).
#### Файлы antennas.txt и satellites.txt

Здесь хранятся данные антенн и спутников соответственно. Значения расположены в порядке, аналогичном конструктору *(название, мощность передатчика, потери в передатчике, диаметр антенны, фокусное расстояние, КПД антенны, рабочая частота)*. Во избежание проблем не рекомендуется изменять файлы вручную. При удалении файлы автоматически создаются после выхода из приложения.
